#   name | version | winget-id | github-repo | verify-command

# winget-id     package id for Windows. "-" means no winget package.
# github-repo   owner/repo for the release download, used on Linux and as the
#               Windows fallback when winget has no package or fails. "-" means
#               the tool is not distributed that way.
# verify-command  run to test whether the tool is already present and working.
#
# Asset filenames are tool-specific and live in the scripts, not here: this
# file records what is needed, the scripts record how to get it.
#
# Pin every version so the toolchain is reproducible across machines and CI.
# "latest" is only acceptable where the vendor does not publish pinned
# installers through the package manager.
#
# On Windows, winget is tried first. Its packages are signed, which matters on
# machines running Smart App Control or WDAC — those policies block unsigned
# executables, including loose binaries pulled from a release page and the
# pip.exe shim.
